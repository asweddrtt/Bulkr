# Bulkr

A cross-platform mobile application tailored specifically to track nutrition and support weight gain. Bulkr combines daily calorie tracking with a social ecosystem to keep users accountable through friends, groups, and an interactive feed.

## Key Features
* **Calorie Tracking:** Log daily meals, monitor macro intake, and maintain the consistent caloric surplus needed for bulking.
* **Feed & Profile:** Share progress, view milestones, and interact with community updates on a personalized social feed.
* **Friends & Groups:** Connect with workout partners, join dedicated fitness groups, and build a supportive accountability network.

## Tech Stack
* Built with **Flutter** and **Dart** **Supabase**
